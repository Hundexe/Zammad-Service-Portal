# Sicherheitsrichtlinie

## Schwachstellen melden

Bitte Sicherheitsprobleme **nicht** als öffentliches Issue melden, sondern vertraulich über **GitHub → Security → Report a vulnerability** in diesem Repository (bzw. bei einer eigenen Installation an die zuständige IT). Hilfreich sind:

- betroffene Version (Verwaltung → Updates),
- Schritte zum Nachvollziehen,
- mögliche Auswirkung.

Wir bestätigen den Eingang innerhalb von zwei Arbeitstagen und melden uns mit einer Einschätzung.

## Unterstützte Versionen

Sicherheitskorrekturen gibt es für die jeweils neueste Version. Updates lassen sich direkt aus der Verwaltung installieren (siehe [docs/UPDATES.md](docs/UPDATES.md)).
